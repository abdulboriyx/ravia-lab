# P2-EG legacy rule demotion

The donor/acceptor, termini, phosphodiester, and cleavage rules in the existing
DNA/RNA presentation modules remain presentation-only legacy visualization
behavior. They may render a legacy owner contract, but are not admissible as
scientific evidence for a P2-E grounding request.

New P2 paths must use validated BCDF substrate evidence and P2-G assertion IDs
through `p2-e-interaction-topology-grounding.ts`. Frozen Foundation/F2 models
remain the destination for topology; neither legacy presentation rules nor P2-G
creates a second SceneSpec or topology authority.
